# Meshvenn Cloth

Independent Blender 5.2 extension for a portable fabric finish. It preserves the base-color image, UVs, mesh and rig, and bakes authored world-space woven detail into tangent-space normal and packed metallic/roughness PNGs. The final material uses standard glTF PBR textures; it does not require procedural shader support in a consumer. Dark base-color regions receive less fabric relief and lower roughness, suitable for the dummy's painted buttons. This is an authored material rule, not semantic recognition or recovered surface detail.

Install the ZIP in Blender Preferences → Get Extensions → Install from Disk. The **Meshvenn → Cloth surface** panel applies the finish to a selected UV-mapped mesh with one baked Principled material. **Detail map resolution** controls the new surface maps; it does not enlarge or sharpen the base-color image. Use Object Mode and the rig's rest pose.

When Meshvenn is enabled, the extension adds the opt-in **Cloth UV Bake** MATERIAL implementation. It calls the existing UV Bake stage, then finishes its material. Increase Meshvenn's base-color bake resolution to 1024 or 2048 before using it. The core does not import this extension. Disable/unregister it to remove its implementation; the standard UV Bake remains available and its default is unchanged.

For the generated native dummy, `scripts/benchmark_stylized_dummy_quality.py` additionally accepts `--texture-size 2048 --coherent-head --cloth --variants detail --cardinal-priority`. The optional head policy derives a vertical head region from explicit native head weights. Front/back views own its dark markings; dark features in side/diagonal sources are excluded with a bounded dilated appearance mask while lateral cloth observations remain available. Masks are intersected with their originals, without altering source images or geometry. The declared artistic rule uses maximum linear RGB below 0.22 and six pixels of dilation at a 627-pixel source height. It requires level source cameras and a saved native projection frame. Excluded or unobserved pixels do not become observed coverage. This policy addresses contradictory generated side-view facial features; it is not general semantic recognition or calibrated multiview reconstruction.

The normal and roughness maps are authored detail, separate from source observations. Color resolution cannot recover detail absent from the original views. Source lighting, some seams and the stylized shape remain visible. Compare actual GLB reimports under matched lighting before choosing a version.
